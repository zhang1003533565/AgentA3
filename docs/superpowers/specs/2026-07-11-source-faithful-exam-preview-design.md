# 源码等价试卷模板与预览设计

## 目标

将 `/Users/zzs/Desktop/zzs/github/wordpapergenerate` 中的试卷生成源码、模板文件和全部版式配置等价迁移到现有 Java 管理后台。`动态试卷.docx` 是模板模式的视觉权威；Java 实现不得凭空重设计版式。

管理后台必须支持：选题后生成预览、调整页面格式、重新预览、确认后保存历史并下载正式试卷和答案。

## 版式权威与迁移边界

以下源文件共同构成迁移依据：

- `generatePaper.js`：页面、边距、字号、表格、题目和简单模式算法。
- `generatePaperByTemplate.js`：模板 ZIP 替换、奇偶页眉、装订线、关系文件和模板模式算法。
- `word/statictemp/document.docx`：基础 DOCX 包。
- `word/document/document.xml` 与关系文件：正文插槽和引用。
- `word/head/header1.xml`、`header2.xml`：奇偶页左右装订、密封信息和定位参数。
- 基础模板内 `footer1.xml`、`footer2.xml`：每张物理纸上的两个逻辑页码。
- `动态试卷.docx`：最终视觉比对样本。

迁移不是调用 Node.js。Java 使用 ZIP 和 XML API对同一 DOCX 包执行等价替换，并保留未修改的样式、编号、页眉页脚、Drawing/VML、字段和关系文件。

## 支持的全部源格式

### 生成模式

- `template`：默认且推荐。以源 DOCX 模板为基础，精确保留参考效果。
- `simple`：保留源项目的简单动态模式，用于不需要复杂装订线的普通试卷。

### 页面参数

- 纸张：A3、A4、B4。
- 方向：横向、纵向。
- 边距：普通、窄、宽、装订线，以及自定义上下左右边距。
- 分栏：1栏、2栏，并保留可配置栏间距；多栏显示分隔线。
- 装订线：启用/禁用；启用时保留奇偶页左右镜像装订结构。
- 页眉信息：煤矿、部门、岗位、姓名等文本可配置。
- 字号：标题、副标题、正文分别配置，默认值与源码一致。
- 其他：标题、副标题、考试时长、总分、注意事项、是否包含答案。

模板模式的 A3 横向默认值必须严格等于参考文件：页面 `23814 x 16840` twips，上下 `1134`、左 `2500`、右 `998`，双栏、栏距 `425`、栏间分隔线、文档网格 `312`。

## Word 生成架构

### 模板资源

将源项目的基础模板和 XML 资源复制到：

`AppBackend/src/main/resources/exam-paper-template/`

资源内保留源包结构。每次生成都把基础模板复制到内存或临时文件，禁止修改资源原件。

### Java 组件

- `SourcePaperTemplateEngine`：读取模板 ZIP、替换正文/页面/关系插槽、更新页眉参数并输出 DOCX。
- `SourcePaperXmlRenderer`：等价移植段落、评分表、阅卷人/得分框、题型标题、选择题、判断题、问答题和答案 XML。
- `SourcePaperLayoutResolver`：实现纸张、方向、边距、分栏、字号和装订线计算。
- `SourcePaperPackageVerifier`：验证生成包包含必需页眉、页脚、关系、字段和正文部件。
- 当前 `ExamPaperDocumentGenerator` 保留为 `simple` 模式实现，模板模式改由新引擎负责。

所有用户文本必须 XML 转义。题库的统一题型结构先转换成源项目题目模型，再进入 XML 渲染器。选择题按源算法决定横排或逐行；非源生题型使用题干、作答区和答案的安全回退，但不得破坏模板布局。

## 预览与确认流程

### 用户流程

1. 用户完成随机或手工选题。
2. 在“页面格式”面板调整生成模式、纸张、方向、边距、栏数、栏距、装订线、字号和页眉信息。
3. 点击“生成预览”。
4. 后端用当前题目与未保存配置生成临时 DOCX。
5. 后端通过 LibreOffice headless 将临时 DOCX 转为 PDF，并返回预览会话。
6. 前端在内嵌 PDF 查看器中分页、缩放预览。
7. 用户调整参数后再次预览；新预览替换旧预览。
8. 用户点击“确认生成”后，服务端重新用相同配置和题目快照生成正式历史记录及下载文件。

预览不能用浏览器 HTML 近似模拟，因为它无法验证 Word 页眉、字段、分栏、分页和浮动装订对象。预览与正式下载必须调用同一个 Java 模板引擎。

### 临时文件生命周期

- 预览会话包含随机 token、创建用户、配置哈希、题目哈希、过期时间和 PDF 地址。
- 会话只允许创建者访问，默认 30 分钟过期。
- DOCX/PDF 存放在服务端临时预览目录，不写入正式历史表。
- 新预览可主动清理同用户旧会话；定时任务删除过期文件。
- 确认生成时不信任预览文件，重新校验题目和配置并生成正式结果。

### LibreOffice 边界

- 增加可配置的 `soffice` 路径、超时和临时目录。
- 转换失败返回明确错误，不保存历史记录。
- 生产环境启动时检测 LibreOffice；不可用时下载 DOCX仍可工作，但“精确预览”明确不可用，不退化为错误的 HTML 预览。

## 数据与接口调整

历史记录新增或扩展布局快照，保存生成模式、边距预设/自定义边距、栏距、装订线、三档字号和页眉信息。历史重新下载必须使用保存的布局快照。

新增接口：

- `POST /api/exam/papers/preview`：接收未保存的试卷信息、题目和完整布局配置，返回预览 token、PDF URL、页数和过期时间。
- `GET /api/exam/papers/preview/{token}`：仅创建者读取 PDF。
- `DELETE /api/exam/papers/preview/{token}`：主动清理预览。
- `POST /api/exam/papers`：确认生成并保存完整布局快照；请求结构与预览共用同一配置 DTO。
- 现有下载接口根据历史布局快照选择 `template` 或 `simple` 引擎。

## 管理后台设计

创建页改为三步工作区：

1. 试卷信息与选题。
2. 页面格式：完整展示源项目支持的参数，并提供“恢复源码默认值”。
3. 预览与确认：左侧/顶部工具栏用于缩放、翻页和重新预览，主体嵌入 PDF；右侧保持页面参数，调整后显示“预览已过期”提示。

只有预览配置哈希与当前表单一致时才允许“确认生成”。修改题目、顺序、分值或版式后，旧预览立即标记失效，必须重新生成。

## 错误处理与安全

- 模板资源缺失、占位符未全部替换、ZIP 部件缺失或 XML 无法解析时拒绝生成。
- LibreOffice 转换使用固定命令参数，不拼接用户输入；文件名使用服务端生成 UUID。
- 预览 token 不使用可预测 ID，PDF 响应禁止公共缓存。
- 所有预览、确认、历史和下载接口要求登录并校验创建者。
- 页面参数设定上下限，防止极端边距、字号或栏距造成不可用文档。
- 生成日志记录模板版本、配置哈希和失败阶段，但不记录题目答案全文。

## 验证与完成标准

### 源码等价单元测试

- 页面尺寸、方向、四种边距、自定义边距、分栏、栏距和字号计算与 JS 源码给定输入输出一致。
- 评分表、阅卷人/得分框、题型标题和题目 XML 包含与源算法相同的结构和关键数值。
- 奇偶页眉、页脚关系、`evenAndOddHeaders`、字段和装订定位参数存在。
- 未替换占位符、缺失模板部件和非法 XML 必须失败。

### 文档视觉回归

- 使用固定题目生成 A3 横向模板试卷，渲染所有页面，与 `动态试卷.docx` 逐页比较。
- 人工检查参考图中的标题、评分表、阅卷框、装订线、灰色密封区、竖排信息、栏间线和逻辑页码。
- 再验证 A4/B4、横纵向、1/2栏、四种边距、装订开关和字体调整不会裁切或重叠。
- 每次版式实现变更都执行 DOCX 渲染检查；只检查 XML 不算完成。

### 预览验收

- 同一配置下预览 PDF 与正式 DOCX渲染结果一致。
- 修改任一布局或题目字段会使旧预览失效。
- 预览只允许创建者读取，过期后不可访问且临时文件被清理。
- LibreOffice 不可用、超时或转换失败时返回明确状态并且不产生历史记录。

## 非目标

- 不调用 Node.js 生成试卷。
- 不用 HTML/CSS 近似替代 Word 精确预览。
- 不修改参考源码目录或 `动态试卷.docx`。
- 不在本轮加入 PDF 正式下载；PDF仅用于临时预览。
