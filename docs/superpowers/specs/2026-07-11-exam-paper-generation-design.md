# 题库试卷生成模块设计

## 目标

在现有管理后台新增“试卷生成”菜单，直接使用 `exam_question` 题库完成随机选题、手工选题、Word 试卷与答案生成，以及历史试卷查询和重复下载。第一版不提供加密 JSON 解密、Excel 导入或可复用的复杂组卷规则模板。

## 用户流程

1. 管理员进入“AI 模块 / 试卷生成”。
2. 填写试卷标题、考试时长、注意事项、页眉信息和版式。
3. 选择随机组卷或手工选题。
4. 在已选题区调整顺序、题目分值或移除题目，页面实时统计题数和总分。
5. 提交后，后端保存试卷和题目快照并生成 Word 内容。
6. 用户可立即下载无答案试卷或答案文档，也可从历史记录中再次下载。

## 功能范围

### 选题

- 随机选题：按题型、难度和数量从状态正常的现有题库中随机抽取。
- 手工选题：复用题库的题型、难度和题干搜索能力，支持跨页添加。
- 去重：同一份试卷不能重复选择同一道题。
- 排序与分值：提交前允许调整题目顺序，并覆盖该题在当前试卷中的分值，不修改题库原始分值。
- 校验：至少选择一道题；分值必须大于零；随机条件对应的题目不足时明确返回缺少数量，不生成不完整试卷。

### Word 输出

- 支持 A3、A4、B4。
- 支持横向和纵向。
- 支持单栏和双栏；双栏带栏间分隔线。
- 支持标题、副标题、考试时长、总分、注意事项和页眉信息。
- 按题型分组展示题目，并显示题型题数、每部分总分。
- 无答案试卷不输出标准答案和解析。
- 答案文档保持与试卷一致的题号，输出标准答案；存在解析时一并输出解析。
- 选择题、判断题按题型结构渲染；其余题型使用统一题干与作答空间，并在答案文档中渲染结构化答案的可读文本。
- 文件名使用经过清理的试卷标题和历史记录编号，避免路径穿越及非法文件名。

## 技术方案

采用纯 Java 实现。Spring Boot 负责业务接口和文件流，Apache POI XWPF 负责 DOCX 生成，必要的分栏、页面尺寸和页面方向通过 POI 暴露的 OOXML 类型配置。不调用 Node.js，不复制参考项目的解密逻辑。

Word 文档按请求即时从数据库快照生成并通过 HTTP 流式下载，不把生成文件永久保存在本地磁盘。这样历史记录不依赖服务器临时文件，部署和清理更简单。

## 数据模型

### `exam_paper`

- `id`：主键。
- `title`：试卷标题。
- `subtitle`：副标题。
- `duration_minutes`：考试时长。
- `precautions`：注意事项。
- `header_info`：页眉/考生信息栏。
- `page_size`：`A3`、`A4`、`B4`。
- `orientation`：`portrait`、`landscape`。
- `columns_count`：`1` 或 `2`。
- `selection_mode`：`random` 或 `manual`。
- `question_count`、`total_score`：生成时统计值。
- `created_by`、`create_time`、`update_time`：审计字段。
- `status`：正常/删除状态，为后续软删除预留。

### `exam_paper_question`

- `id`、`paper_id`、`question_id`。
- `sort_order`：整份试卷中的稳定顺序。
- `section_order`：题型分组顺序。
- `score`：本试卷题目分值。
- `type`、`stem`、`body_json`、`answer_json`、`analysis`、`scoring_json`：生成时快照。

历史下载只读取快照字段，不读取当前题库内容，因此题库后续修改不会改变旧试卷。

## 后端边界与接口

新增 `ExamPaperController`、`ExamPaperService`、两个实体与对应仓库，并将 Word 排版隔离为 `ExamPaperDocumentGenerator`。控制器沿用现有 `request.getAttribute("userId")` 登录校验。

- `POST /api/exam/papers/random-preview`：按条件随机选题，只返回候选题，不保存试卷。
- `POST /api/exam/papers`：校验题目、保存试卷与快照，返回历史记录详情。
- `GET /api/exam/papers`：分页查询历史试卷，默认仅显示当前登录用户创建的记录。
- `GET /api/exam/papers/{id}`：查询试卷和题目明细。
- `GET /api/exam/papers/{id}/download?content=paper`：下载无答案试卷。
- `GET /api/exam/papers/{id}/download?content=answer`：下载答案文档。

创建接口在单个事务内保存主表和题目快照。文档生成失败不破坏已经保存的历史记录；用户可以修复环境后再次下载。不存在、无权访问、题库数量不足和不支持的版式均返回明确业务错误。

## 前端设计

在 `portalData.js` 的 AI 模块中新增“试卷生成”，路由为 `/ai/exam-papers`，并在门户卡片中增加入口。

页面包含两个页签：

- 创建试卷：基础信息、版式配置、随机/手工选题、已选题列表和提交按钮。
- 历史试卷：分页表格、筛选、详情、试卷下载和答案下载。

随机选题以题型配置行表达，每行包含题型、难度和数量。手工选题使用可选择表格，已加入题目在跨页切换后仍保留。已选题表格支持上移、下移、分值编辑和移除。

前端提交后不自动依赖浏览器缓存中的题目详情，而以服务端返回的历史记录为准。文件下载使用鉴权请求获取 Blob，并从 `Content-Disposition` 解析文件名。

## 安全与一致性

- 所有接口要求登录；历史记录仅允许创建者访问和下载。
- 服务端重新查询提交的题目 ID，拒绝不存在或已停用的题目。
- 服务端计算题数和总分，不信任前端统计值。
- 随机选择使用数据库筛选后的候选集合和无放回抽样。
- 对标题、页眉和其他文本设置长度限制；下载响应固定 DOCX MIME 类型。
- JSON 解析失败时保留安全的纯文本回退，不让单道异常题目导致整个文档产生不可诊断错误。

## 测试与验收

### 后端测试

- 随机选题满足题型、难度、数量且不重复。
- 候选题不足时返回明确错误。
- 创建试卷会保存稳定顺序、覆盖分值和完整快照。
- 历史记录只对创建者可见。
- 六种纸张与方向组合均能生成可打开的 DOCX。
- 单栏、双栏、无答案试卷和答案文档内容正确。
- 题库内容修改后，历史试卷下载内容保持不变。

### 前端验证

- 随机和手工两条流程均能完成创建。
- 手工选择跨页保留且不能重复。
- 总题数和总分随编辑实时更新。
- 历史分页、详情和两个下载按钮可用。
- 新菜单和路由在桌面及窄屏布局下可访问。

### 完成标准

- 后端测试通过，Maven 构建成功。
- 前端 lint/build 通过。
- 实际生成至少一份 A3 横向双栏和一份 A4 纵向单栏文档，并验证 DOCX 包结构可读取。
- 第一版不实现组卷规则模板、题库导入、解密、在线 Word 预览或 PDF 导出。
