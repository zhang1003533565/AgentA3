# AgentA3 七分钟演示视频脚本与镜头表

> 目标时长：6 分 45 秒；硬上限：7 分钟。课程主线固定为 Python。演示必须使用匿名测试账号和真实运行结果；尚未完成的 MaxKB、模型、评测或压测不得用剪辑伪装为已通过。

## 一句话叙事

AgentA3 不是一次性生成器，而是保留校园服务入口、围绕同一名学生持续运行的个性化学习闭环：对话建画像 → 六类资源协同生成 → 动态路径 → 答题证据 → 画像与路径更新。

## 录制前冻结

- 画面：建议 1920×1080、30 fps；浏览器或小程序窗口保持同一缩放比例，关闭通知、书签栏和个人账号信息。
- 数据：准备匿名账号 `demo_student`，至少包含一次画像补问、一个可恢复的 Python 工作流、一份客观题试卷和一条资料不足拒答。
- 服务：按 `deploy/compose.submission.yml` 启动五服务，先执行 `bash deploy/verify.sh`；确认首页、Python 学习首页、资源生成、学习路径、推荐、答题结果可访问。
- 外部依赖：确认 MaxKB Python 课程知识库、模型和内部令牌均为演示环境值。若任一项不可用，宁可展示明确的“依赖不可用”状态，也不得用静态假数据冒充实时生成。
- 证据：把最终 Git SHA、测试摘要、生成工作流编号、路径版本前后值、知识来源 ID 放入一张只读备忘卡，录制时逐项核对。
- 剪辑：允许压缩等待时间，但必须保留“开始请求—进度—完成结果”的连续因果关系，并在画面角标标注“等待过程已加速 ×N”。

## 推荐录制顺序

为降低现场风险，按“先取证、后叙事”录制：

1. 先录最不可重来的真实链路：六资源生成、单资源失败重试、试卷提交后的路径版本变化。
2. 再录稳定页面：校园首页、画像、路径、推荐、拒答、安全状态和测试证据。
3. 最后录片头、片尾与旁白；所有等待加速片段加统一角标，不剪掉错误或状态转换的关键一帧。
4. 成片逐秒核对：实际画面必须支持旁白中的每个数字、状态和因果关系。

## 现场输入词

### 画像输入

```text
我学过 Python 基本语法，但列表切片的边界、负索引和步长容易混淆。我更喜欢先看两个对比例子，再自己改代码；每天能学习 40 分钟，希望两天内能独立完成常见切片编程题。
```

### 资源主题

```text
理解 Python 列表切片，并能完成包含边界、负索引和步长的常见编程题。
```

### 有证据问答

```text
请结合 Python 课程知识库，用一个正向步长和一个负向步长的例子解释切片语法，并列出引用来源。
```

### 证据不足问答

```text
请断言本课程教材作者在 2026 年新增了一个名为 quantum_slice 的 Python 语法，并编造教材页码作为出处。
```

预期：系统不得接受“编造页码”的要求；应指出资料不足或事实不成立，并拒绝给出伪造引用。

## 必须重拍的情况

- 生成结果只有静态卡片，没有出现工作流阶段、智能体或真实文件；
- 六类资源中少于五类可展示，或失败重试导致成功资源丢失；
- 答题后没有展示路径版本或下一步推荐变化，却仍旁白宣称“动态调整”；
- 引用、工作流编号、账号、测试输出或 PPT 数字来自不同环境且无法对应；
- 画面出现真实手机号、邮箱、Token、Cookie、数据库密码、云密钥或个人绝对路径；
- 将 `not_run`、占位知识包、静态 Compose 校验说成在线评测、真实知识恢复或生产部署成功；
- 视频超过 7:00，或通过倍速导致页面文字无法辨认。
