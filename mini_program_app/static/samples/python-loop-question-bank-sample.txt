Python 程序设计基础 · 第 3 章 循环结构

【学习目标】
1. 理解循环在程序中的作用：重复执行某一段逻辑，直到条件不满足或遍历结束。
2. 掌握 for 循环与 while 循环的适用场景与基本写法。
3. 理解 break 与 continue 对循环流程的影响。
4. 能够根据题目选择合适的循环方式，并解释简单代码的执行结果。

--------------------------------------------------
3.1 for 循环
--------------------------------------------------

for 循环最适合处理“需要反复遍历一个序列中的每个元素”的场景。
常见可迭代对象包括：列表（list）、元组（tuple）、字符串（str）、range 对象等。

基本形式：
for 变量 in 可迭代对象:
    循环体

示例：
numbers = [1, 2, 3, 4]
total = 0
for n in numbers:
    total = total + n
# 执行结束后 total 的值为 10

使用 range 生成整数序列时：
range(5) 表示 0, 1, 2, 3, 4
range(1, 5) 表示 1, 2, 3, 4
range(1, 10, 2) 表示 1, 3, 5, 7, 9

注意：
- for 循环的次数通常由可迭代对象的长度决定，不需要程序员手动维护计数器。
- 如果目标是“把一组已知数据逐个处理”，优先考虑 for。

--------------------------------------------------
3.2 while 循环
--------------------------------------------------

while 循环根据条件反复执行，适合“事先不知道要循环多少次，只知道停止条件”的场景。

基本形式：
while 条件:
    循环体

示例：
count = 0
while count < 3:
    print(count)
    count = count + 1
# 输出 0 1 2，然后条件变为假，循环结束

注意事项：
1. 必须在循环体内更新与条件相关的变量，否则可能造成死循环。
2. 当循环次数不固定（例如持续读取用户输入直到输入 quit）时，while 更合适。
3. 如果只是遍历列表或字符串，通常 for 比 while 更清晰。

for 与 while 的对比：
- for：面向遍历，适合序列、range、固定集合。
- while：面向条件，适合未知次数、等待某一条件成立或失败。

--------------------------------------------------
3.3 break 与 continue
--------------------------------------------------

break：立即结束整个循环，不再执行后续轮次。
continue：结束本轮循环，直接进入下一轮判断或下一轮遍历。

示例 A（break）：
for n in [1, 2, 3, 4, 5]:
    if n == 3:
        break
    print(n)
# 输出 1 2，遇到 3 后循环结束，不会打印 3、4、5

示例 B（continue）：
for n in [1, 2, 3, 4, 5]:
    if n == 3:
        continue
    print(n)
# 输出 1 2 4 5，跳过 3，但循环会继续

常见考点：
1. break 影响的是“整个循环”，不是只跳过一个语句。
2. continue 不会终止循环，只跳过当前轮次剩余语句。
3. 在嵌套循环中，break / continue 默认只作用于最近一层循环。

--------------------------------------------------
3.4 综合练习材料（可用于出题）
--------------------------------------------------

题景一：
给定列表 scores = [60, 75, 90, 45, 88]，要求统计及格（>=60）的人数。
这更适合使用 for 遍历列表，并在循环中用条件判断累加计数。

题景二：
用户不断输入整数，直到输入 -1 停止，然后输出已输入数字的平均值。
由于循环次数未知，更适合 while；输入 -1 时使用 break 结束。

题景三：
打印 1 到 20 中所有不被 3 整除的数。
可用 for + range，并在被 3 整除时 continue。

关键术语汇总：
循环、迭代、可迭代对象、for、while、range、死循环、break、continue、循环体、遍历、条件表达式、计数器。

复习提示：
出题时应区分“会不会选循环类型”“能不能读懂 break/continue”“能否根据场景写出正确控制流”。
材料中的示例代码、对比结论和注意事项，都可以转化为单选、判断、填空或简答题。
