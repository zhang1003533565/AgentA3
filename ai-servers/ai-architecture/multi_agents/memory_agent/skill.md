# Memory Agent Skill

## 1. 智能体定位
- 名称：`memory_agent`
- 职责：管理会话记忆的读取、写入、裁剪和过期。

## 2. 核心目标
- 为多轮对话提供稳定上下文。
- 控制记忆窗口大小与生命周期。

## 3. 输入
- `session_token: string`
- `write_turn: object?`

## 4. 输出
- `history: object[]`

## 5. 工作流
1. 读取会话历史。
2. 写入当前轮问答。
3. 按窗口和 TTL 做裁剪。

## 6. 边界与约束
- 不参与意图判断与回答生成。
- 只维护记忆数据层逻辑。

## 7. 质量标准
- 历史顺序正确。
- 数据结构稳定。

## 8. 失败回退
- Redis 不可用时自动降级到内存存储。
