# Graph Agent Skill

## 1. 智能体定位
- 名称：`graph_agent`
- 职责：从知识图谱中检索实体关系与证据路径。

## 2. 核心目标
- 提供结构化实体关系证据。
- 支持 GraphRAG 场景下的可解释回答。

## 3. 输入
- `user_query: string`

## 4. 输出
- `entities: object[]`
- `relations: object[]`
- `evidence_paths: object[]`

## 5. 工作流
1. 实体识别与链接。
2. 关系与路径检索。
3. 返回高相关图证据。

## 6. 边界与约束
- 不生成最终自然语言答案。
- 不返回无来源的图关系。

## 7. 质量标准
- 实体链接准确。
- 路径证据可复现。

## 8. 失败回退
- 图检索失败时返回空图证据并提示走文本检索链路。
