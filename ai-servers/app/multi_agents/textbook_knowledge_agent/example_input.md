数据结构：栈与队列

栈是限定只能在表的一端进行插入和删除操作的线性表，允许操作的一端称为栈顶。栈遵循后进先出原则。入栈表示把元素压入栈顶，出栈表示删除并返回栈顶元素。

栈的顺序存储结构通常用数组实现，需要记录栈顶指针。栈空和栈满是顺序栈的关键边界条件。链式栈使用链表实现，通常不需要预先确定容量。

队列是限定只能在一端插入、另一端删除的线性表。队尾负责插入，队头负责删除。队列遵循先进先出原则。

循环队列可以解决顺序队列“假溢出”问题。常见判空条件为 front == rear，常见判满条件为 (rear + 1) % maxSize == front。

栈的典型应用包括括号匹配、表达式求值、递归调用和深度优先搜索。队列的典型应用包括任务排队、打印缓冲、广度优先搜索和消息队列。
