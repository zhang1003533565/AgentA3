数据结构：栈与队列

栈和队列都是线性表，但操作受限。栈只允许在栈顶进行插入和删除，队列只允许在队尾插入、队头删除。

栈的特点是后进先出。常见操作包括初始化、判空、入栈、出栈、读取栈顶元素。顺序栈需要关注栈顶指针和容量限制，链栈可以动态分配结点。

队列的特点是先进先出。常见操作包括初始化、判空、入队、出队、读取队头元素。循环队列通过取模运算让数组空间循环使用，可减少假溢出。

常见应用：括号匹配和表达式求值通常使用栈；广度优先搜索、打印任务排队和消息缓冲通常使用队列。

易错点：循环队列中 front == rear 通常表示队空；若采用牺牲一个存储单元的实现，队满条件为 (rear + 1) % maxSize == front。
