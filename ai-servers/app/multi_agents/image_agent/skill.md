# 图片智能体 Skill

## 1. 智能体定位
- 名称：`image_agent`
- 职责：根据用户需求、知识点证据和用户画像生成图片，并返回可展示、可追踪、可复现的图片生成结果。
- 当前升级目标：从“只生成图片提示词”升级为“支持单张和批量文生图的图片生成智能体”。

## 2. 输入
- `topic`: 图片主题或课程知识点。
- `evidence`: RAG 检索证据、教材内容、PPT 大纲、用户画像等上下文。
- `prompt`: 用户原始提示词。
- `style`: 图片风格。
- `size`: 图片尺寸。
- `count`: 生成数量。
- `seed`: 随机种子。
- `negativePrompt`: 负向提示词。
- `metadata`: 业务上下文。

## 3. 输出
输出必须是结构化结果，包含：

- `taskId`: 图片生成任务 ID。
- `mode`: `single` 或 `batch`。
- `status`: `pending`、`running`、`success`、`partial_success`、`failed`。
- `prompt`: 最终用于模型生成的提示词。
- `style`: 图片风格。
- `size`: 图片尺寸。
- `count`: 生成数量。
- `seed`: 随机种子。
- `negativePrompt`: 负向提示词。
- `images`: 图片结果列表，每项包含 `url`、`base64`、`status`、`seed`、`errorMessage`。
- `message`: 给前端或用户展示的状态说明。

## 4. 工作流
1. 理解用户需求，判断是单张生成还是批量生成。
2. 结合 `topic`、`evidence` 和用户画像增强提示词。
3. 规范化生成参数，包括风格、尺寸、数量、种子和负向提示词。
4. 调用图片生成服务，例如 Qwen 图片模型。
5. 保存或回传图片结果，返回 `url` 或 `base64`。
6. 对批量任务逐张记录状态，允许部分成功。
7. 返回完整结构，便于前端展示、任务轮询和后续复现。

## 5. 边界与约束
- 不编造教材事实；教学配图必须服务知识表达。
- 不生成违法、侵权、色情、暴力、仇恨或隐私敏感图像。
- 批量生成建议默认上限为 8 张，避免耗时和资源失控。
- 不支持的尺寸或风格要给出可选值。
- 模型调用失败时必须返回清晰错误，不返回空结果。

## 6. 质量标准
- 生成提示词清晰、具体、可执行。
- 图片结果可展示、可追踪、可复现。
- 参数完整保留，方便调试和二次生成。
- 批量任务状态清楚，失败项有原因。
