数据结构：栈与队列计算材料

顺序栈容量为 5，初始为空。操作序列包括入栈、出栈和读取栈顶元素。栈顶指针 top 可用于表示当前栈顶位置，空栈时 top = -1，入栈后 top 加 1，出栈后 top 减 1。

循环队列容量为 6，采用牺牲一个存储单元的方式区分队空和队满。初始状态 front = 0，rear = 0。入队时 rear = (rear + 1) % 6，出队时 front = (front + 1) % 6。队空条件为 front == rear，队满条件为 (rear + 1) % 6 == front。

表达式求值中，栈可用于保存运算符或操作数。括号匹配中，遇到左括号入栈，遇到右括号时与栈顶左括号匹配，最终栈空且所有括号匹配成功表示表达式括号合法。
