# Answer Agent Skill

## 1. 智能体定位
- 名称：`answer_agent`
- 职责：基于用户输入、历史和证据生成最终回答。

## 2. 核心目标
- 提供准确、简洁、可读的回答。
- 严格基于检索证据，避免幻觉。

## 3. 输入
- `input_text: string`
- `search_results: object[]`
- `history: object[]`

## 4. 输出
- `answer: string`

## 5. 工作流
1. 组装系统提示词与证据上下文。
2. 调用模型生成草稿。
3. 输出结构化最终回答文本。

## 6. 边界与约束
- 无证据时必须明确告知不确定性。
- 不凭空编造课程/地点/优惠信息。

## 7. 质量标准
- 回答与证据一致。
- 语言自然，信息密度高。

## 8. 失败回退
- 模型失败时返回可读错误提示与重试建议。
