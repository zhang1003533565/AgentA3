# Contract

## Agent
- `architecture_prompt_agent`

## Input
- `topic`: 用户输入的主题、系统说明或架构描述
- `evidence`: 检索证据、模块说明、依赖信息、数据流信息

## Output
- `architecture_prompt_text`（纯文本模板）

## Output Schema
- 标题：`架构图提示词模板`
- 固定字段：
  - `图类型`
  - `核心目标`
  - `节点清单`
  - `关系清单`
  - `分层分组`
  - `布局要求`
  - `风格要求`
  - `必须包含文案`
  - `禁止事项`
  - `最终出图提示词`

## Transfer Rule
- 输出用于人工复制给下游架构图智能体。
- 人工复制时，优先复制整份模板；如果下游智能体只接受一句话，可优先复制 `最终出图提示词` 字段。
- 所有字段都必须保持纯文本，不输出 JSON、代码块或 Mermaid。

## Error Handling
- 输入为空时返回可读提示。
- 证据不足时输出“暂无足够证据，已按主题生成通用架构图提示词”。
