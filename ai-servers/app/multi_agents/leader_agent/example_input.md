数据结构：栈与队列

栈是一种只允许在同一端进行插入和删除操作的线性表，操作端称为栈顶，另一端称为栈底。栈的核心特点是后进先出。常见操作包括入栈、出栈、取栈顶元素、判空和判满。

队列是一种只允许在一端插入、另一端删除的线性表，插入端称为队尾，删除端称为队头。队列的核心特点是先进先出。常见操作包括入队、出队、取队头元素、判空和判满。

顺序栈通常使用数组实现，需要关注栈满和栈空条件。链栈通常使用链表实现，空间分配更灵活。

循环队列通过取模运算复用数组空间。为了区分队空和队满，常见做法是牺牲一个存储单元：队空条件为 front == rear，队满条件为 (rear + 1) % maxSize == front。

典型应用：栈可用于括号匹配、表达式求值、函数调用和回溯；队列可用于任务调度、缓冲区、广度优先搜索和打印队列。
