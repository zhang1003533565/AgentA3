数据结构：栈与队列

课程主题：栈与队列的概念、操作和应用。

栈是后进先出的线性表，只能在栈顶进行插入和删除。核心操作包括入栈、出栈、取栈顶元素、判空和判满。典型应用包括括号匹配、表达式求值、函数调用和回溯。

队列是先进先出的线性表，只能在队尾插入、队头删除。核心操作包括入队、出队、取队头元素、判空和判满。典型应用包括任务调度、打印队列、消息缓冲和广度优先搜索。

循环队列通过取模运算复用数组空间。采用牺牲一个存储单元时，front == rear 表示队空，(rear + 1) % maxSize == front 表示队满。

课堂重点：比较栈和队列的操作限制、存储结构、典型场景和边界条件。
