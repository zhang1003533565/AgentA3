# 校园市集迁移恢复方案

## 原则
- 直接复制旧项目代码（不重新设计）
- 不改后端 API
- 不删新版组件
- 保留新版已有的独立页面（lostfoundDetail、lostfoundChat、myItems、myMessages 等）

---

## 文件 1：恢复 `lostfoundList.vue`（核心列表页）

**操作**：用旧版文件（2722行）直接覆盖新版（1614行）

**原因**：旧版包含完整的市集浏览体验：
- 学校名称头部 + 定位图标
- market-search-entry 搜索动画组件
- 场景标签（毕业急出/免费低价/考研教材/同楼自提）
- 4列分类网格 category-shell
- 排序栏（最新/热门 + 筛选按钮）
- 完整筛选面板（分类/价格/时间/状态/位置/属性筛选 + 底部弹出动画）
- market-bottom-bar 底部导航
- 搜索 Overlay 动画

**风险**：低。旧版内嵌的 SPA 子页面（detail/chat/myItems/myMessages）在新版中已有独立页面，旧版也通过 uni.navigateTo 跳转到外部页面，不会冲突。

## 文件 2：恢复 `pages/market/message/message.vue`（消息聚合页）🆕

**操作**：
- 新建目录 `AppFrontend/pages/market/message/`
- 从旧项目复制 `message.vue`（408行）
- 在 `pages.json` 主包 pages 数组中注册该页面
- 在 `preloadRule` 中不添加（消息页按需加载）
- 在 `market-bottom-bar.vue` 中将 `goToMessages()` 的目标从 `/subpackage_lostfound/myMessages/myMessages` 改回 `/pages/market/message/message`

**适配修改**：旧版调用了 `markTradeMessagesRead(sessionId)` API（新版后端已删除），需要改为新 API 或简化逻辑：
- 方案：移除 `goToTradeNotifications()` 中的预标记逻辑，由 `marketTradeNotifications` 页面自行处理已读标记

**原因**：这是完整的消息聚合中心，包含系统通知入口（带红点）+ 交易通知入口（带红点）+ 聊天会话列表 + 商品名 + 未读红点。
