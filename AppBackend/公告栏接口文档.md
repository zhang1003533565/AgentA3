# 公告栏管理接口文档

> **基础路径**: `http://localhost:8080`
> **认证方式**: JWT Bearer Token（在 Header 中添加 `Authorization: Bearer <token>`）
> **说明**: 仅 `getEnabledAnnouncements`、`getAnnouncementById` 接口无需认证，其余接口需管理员（ADMIN）或教师（TEACHER）权限。

---

## 1. 创建公告

创建新公告。

**请求**

```
POST /api/announcements
Content-Type: application/json
Authorization: Bearer <token>
```

**请求体**

```json
{
  "title": "关于2026年春季学期开学通知",
  "content": "各位师生员工，新学期将于3月1日正式开始，请提前做好返校准备...",
  "sortOrder": 0,
  "enabled": true
}
```

| 参数名    | 类型    | 必填 | 说明                          | 示例值           |
|-----------|---------|------|-------------------------------|------------------|
| title     | String  | 是   | 公告标题（≤200字符）          | 开学通知         |
| content   | String  | 是   | 公告内容（文字段落）          | 各位师生...      |
| sortOrder | Integer | 否   | 排序值，值越小越靠前，默认0   | 0                |
| enabled   | Boolean | 否   | 是否启用，默认 true            | true             |

**请求示例（curl）**

```bash
curl -X POST "http://localhost:8080/api/announcements" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -d '{"title":"关于2026年春季学期开学通知","content":"各位师生员工，新学期将于3月1日正式开始...","sortOrder":0,"enabled":true}'
```

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "公告创建成功",
  "data": {
    "id": 1,
    "title": "关于2026年春季学期开学通知",
    "content": "各位师生员工，新学期将于3月1日正式开始，请提前做好返校准备...",
    "sortOrder": 0,
    "enabled": true,
    "createTime": "2026-03-01 10:00:00",
    "updateTime": "2026-03-01 10:00:00"
  }
}
```

**错误码**

| 错误码 | 说明                     |
|--------|--------------------------|
| 401    | 未登录或 Token 无效      |
| 403    | 无权限，仅管理员/教师可操作 |
| 400    | 标题或内容为空           |

## 2. 获取已启用的公告

获取所有已启用的公告，供前端展示用，无需权限。

**请求**

```
GET /api/announcements/enabled
```

**参数**: 无

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "id": 1,
      "title": "关于2026年春季学期开学通知",
      "content": "各位师生员工，新学期将于3月1日正式开始，请提前做好返校准备...",
      "sortOrder": 0,
      "enabled": true,
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    },
    {
      "id": 2,
      "title": "图书馆开放时间调整",
      "content": "自本周起，图书馆开放时间调整为早8点至晚10点...",
      "sortOrder": 1,
      "enabled": true,
      "createTime": "2026-03-02 09:00:00",
      "updateTime": "2026-03-02 09:00:00"
    }
  ]
}
```

> **说明**: 返回结果按 `sortOrder` 升序排列，即排序值越小越靠前。

## 5. 更新公告

更新指定 ID 的公告信息，需管理员或教师权限。

**请求**

```
PUT /api/announcements/{id}
Content-Type: application/json
Authorization: Bearer <token>
```

**路径参数**

| 参数名 | 类型 | 必填 | 说明   | 示例 |
|--------|------|------|--------|------|
| id     | Long | 是   | 公告ID | 1    |

**请求体**

```json
{
  "title": "更新后的公告标题",
  "content": "更新后的公告内容...",
  "sortOrder": 2,
  "enabled": true
}
```

| 参数名    | 类型    | 必填 | 说明                          | 示例值    |
|-----------|---------|------|-------------------------------|-----------|
| title     | String  | 否   | 公告标题                      | 新标题    |
| content   | String  | 否   | 公告内容                      | 新内容    |
| sortOrder | Integer | 否   | 排序值                        | 2         |
| enabled   | Boolean | 否   | 是否启用（true/false）        | true      |

> **说明**: 所有字段均为可选，仅更新传入的字段。不传则保持原值。

**请求示例（curl）**

```bash
curl -X PUT "http://localhost:8080/api/announcements/1" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -d '{"title":"更新后的公告标题","content":"更新后的内容...","sortOrder":2,"enabled":true}'
```

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "公告更新成功",
  "data": {
    "id": 1,
    "title": "更新后的公告标题",
    "content": "更新后的内容...",
    "sortOrder": 2,
    "enabled": true,
    "createTime": "2026-03-01 10:00:00",
    "updateTime": "2026-03-05 15:30:00"
  }
}
```

**错误码**

| 错误码 | 说明                     |
|--------|--------------------------|
| 401    | 未登录或 Token 无效      |
| 403    | 无权限，仅管理员/教师可操作 |
| 404    | 公告不存在               |

## 6. 删除公告

删除指定 ID 的公告，需管理员或教师权限。

**请求**

```
DELETE /api/announcements/{id}
Authorization: Bearer <token>
```

**路径参数**

| 参数名 | 类型 | 必填 | 说明   | 示例 |
|--------|------|------|--------|------|
| id     | Long | 是   | 公告ID | 1    |

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "公告删除成功",
  "data": null
}
```

**错误码**

| 错误码 | 说明                     |
|--------|--------------------------|
| 401    | 未登录或 Token 无效      |
| 403    | 无权限，仅管理员/教师可操作 |
| 404    | 公告不存在               |

---

## 通用响应格式

| 字段 | 类型   | 说明               |
|------|--------|--------------------|
| code | Int    | 状态码，200表示成功 |
| msg  | String | 消息               |
| data | Object | 返回数据           |

## 公共错误码

| 错误码 | 说明             |
|--------|------------------|
| 200    | 成功             |
| 400    | 请求参数错误     |
| 401    | 未登录/Token无效 |
| 403    | 无权限           |
| 404    | 资源不存在       |
| 500    | 服务器内部错误   |

## 附录：数据库表结构

**announcement 表**

| 字段       | 类型     | 说明                           |
|------------|----------|--------------------------------|
| id         | BIGINT   | 主键，自增                     |
| title      | VARCHAR  | 公告标题（≤200字符）           |
| content    | TEXT     | 公告内容                       |
| sort_order | INT      | 排序值，默认0，值越小越靠前    |
| enabled    | TINYINT  | 是否启用：0-禁用，1-启用，默认1 |
| create_time| DATETIME | 创建时间                       |
| update_time| DATETIME | 更新时间                       |

> **说明**: JPA 的 `ddl-auto: update` 模式会在启动时自动创建或更新表结构，无需手动执行 SQL。
