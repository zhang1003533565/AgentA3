| type | Integer | 否 | 设施类型：1-餐厅 2-运动场 3-教学楼 4-宿舍 |

## 六、数据一致性保障

### 6.1 设计原则

| 原则 | 说明 |
|------|------|
| **单一数据源** | 经纬度只存储在 `campus_facility` 表中，地图标记通过 `facility_id` 关联获取 |
| **实时同步** | 地图标记的经纬度均从设施表实时查询 |
| **级联操作** | 设施删除时，标记自动失效（逻辑删除） |

### 6.2 与第四阶段地图模块的关联

```
campus_facility 表（设施表）
  - id, facility_name, longitude, latitude  ← 位置数据单一来源

map_marker 表（地图标记）
  - 1:1 ← campus_facility.facility_id  ← 标记自动关联设施位置
```

### 6.3 设施创建时自动创建标记

当管理员在第三阶段创建设施时，系统自动在第四阶段的 `map_marker` 表中创建对应的标记记录：

```java
// 创建设施时自动创建标记（Service层实现）
@Transactional
public void createFacility(FacilityDTO dto) {
    // 1. 创建设施（包含经纬度）
    CampusFacility facility = new CampusFacility();
    facility.setLongitude(dto.getLongitude());
    facility.setLatitude(dto.getLatitude());
    facilityMapper.insert(facility);

    // 2. 自动创建地图标记
    MapMarker marker = new MapMarker();
    marker.setFacilityId(facility.getId());
    marker.setStatus(1);
    markerMapper.insert(marker);
}
```

### 6.4 逻辑删除保障数据完整性

为防止设施删除导致关联数据失效，使用逻辑删除：

```sql
-- campus_facility 表增加 deleted 字段
ALTER TABLE campus_facility ADD COLUMN deleted TINYINT DEFAULT 0;

-- map_marker 表增加 deleted 字段
ALTER TABLE map_marker ADD COLUMN deleted TINYINT DEFAULT 0;

-- 删除时执行逻辑删除
UPDATE campus_facility SET deleted = 1 WHERE id = ?;
UPDATE map_marker SET deleted = 1 WHERE facility_id = ?;

-- 查询时过滤已删除数据
SELECT * FROM campus_facility WHERE id = ? AND deleted = 0;
SELECT * FROM map_marker WHERE facility_id = ? AND deleted = 0;
```
