# 活动通知管理接口文档

> **基础路径**: `http://localhost:8080`
> **认证方式**: JWT Bearer Token（在 Header 中添加 `Authorization: Bearer <token>`）
> **说明**:
> - 公开接口：`getNoticeList`、`getNoticeById`、`getNoticesByActivity`，无需登录
> - 管理接口：`createNotice`、`updateNotice`、`deleteNotice`，需管理员（ADMIN）或教师（TEACHER）权限

---

## 1. 获取通知列表

分页获取通知列表，支持按活动ID、标题、状态筛选。

**请求**

```
GET /api/activity-notices
```

**Query 参数**

| 参数名     | 类型   | 必填 | 说明                                      | 示例值         |
|------------|--------|------|-------------------------------------------|----------------|
| activityId | Long   | 否   | 活动ID                                    | 1              |
| title      | String | 否   | 通知标题（模糊查询）                      | 讲座           |
| status     | String | 否   | 通知状态：DRAFT-草稿，PUBLISHED-已发布    | PUBLISHED      |
| pageNum    | Integer | 否   | 页码，默认1                              | 1              |
| pageSize   | Integer | 否   | 每页数量，默认10                         | 10             |

**权限**: 公开，无需登录

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "total": 20,
    "records": [
      {
        "id": 1,
        "activityId": 1,
        "title": "讲座时间变更通知",
        "content": "原定于周五的讲座因故推迟到周六...",
        "publisherId": 1001,
        "publisherName": "张老师",
        "status": "PUBLISHED",
        "publishTime": "2026-03-01 10:00:00",
        "createTime": "2026-03-01 10:00:00",
        "updateTime": "2026-03-01 10:00:00"
      }
    ],
    "pageNum": 1,
    "pageSize": 10
  }
}
```

## 2. 获取通知详情

根据通知ID获取通知详细信息。

**请求**

```
GET /api/activity-notices/{id}
```

**路径参数**

| 参数名 | 类型 | 必填 | 说明   | 示例 |
|--------|------|------|--------|------|
| id     | Long | 是   | 通知ID | 1    |

**权限**: 公开，无需登录

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 1,
    "activityId": 1,
    "title": "讲座时间变更通知",
    "content": "原定于周五的讲座因故推迟到周六，请各位同学相互转告。",
    "publisherId": 1001,
    "publisherName": "张老师",
    "status": "PUBLISHED",
    "publishTime": "2026-03-01 10:00:00",
    "createTime": "2026-03-01 10:00:00",
    "updateTime": "2026-03-01 10:00:00"
  }
}
```

**错误码**

| 错误码 | 说明         |
|--------|--------------|
| 404    | 通知不存在   |

## 3. 创建通知

创建新通知。

**请求**

```
POST /api/activity-notices
Content-Type: application/json
Authorization: Bearer <token>
```

**权限**: 管理员或教师

**请求体**

| 参数名      | 类型   | 必填 | 说明                                 | 示例值              |
|-------------|--------|------|--------------------------------------|---------------------|
| activityId  | Long   | 是   | 关联活动ID                           | 1                   |
| title       | String | 是   | 通知标题                             | 讲座时间变更通知     |
| content     | String | 否   | 通知内容                             | 原定于周五...        |
| status      | String | 否   | 通知状态：DRAFT/PUBLISHED，默认PUBLISHED | PUBLISHED         |

```json
{
  "activityId": 1,
  "title": "讲座时间变更通知",
  "content": "原定于周五的讲座因故推迟到周六，请各位同学相互转告。",
  "status": "PUBLISHED"
}
```

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "通知创建成功",
  "data": {
    "id": 1,
    "activityId": 1,
    "title": "讲座时间变更通知",
    "content": "原定于周五的讲座因故推迟到周六，请各位同学相互转告。",
    "publisherId": 1001,
    "publisherName": "张老师",
    "status": "PUBLISHED",
    "publishTime": "2026-03-01 10:00:00",
    "createTime": "2026-03-01 10:00:00",
    "updateTime": "2026-03-01 10:00:00"
  }
}
```

**错误码**

| 错误码 | 说明                     |
|--------|--------------------------|
| 401    | 未登录或 Token 无效      |
| 403    | 无权限，仅管理员/教师可操作 |
| 400    | 参数错误                 |

## 4. 更新通知

更新指定ID的通知信息。

**请求**

```
PUT /api/activity-notices/{id}
Content-Type: application/json
Authorization: Bearer <token>
```

**权限**: 管理员或教师

**路径参数**

| 参数名 | 类型 | 必填 | 说明   | 示例 |
|--------|------|------|--------|------|
| id     | Long | 是   | 通知ID | 1    |

**请求体**（所有字段均为可选）

| 参数名      | 类型   | 必填 | 说明                                 | 示例值              |
|-------------|--------|------|--------------------------------------|---------------------|
| activityId  | Long   | 否   | 关联活动ID                           | 1                   |
| title       | String | 否   | 通知标题                             | 新标题               |
| content     | String | 否   | 通知内容                             | 新内容...            |
| status      | String | 否   | 通知状态：DRAFT/PUBLISHED            | PUBLISHED           |

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "通知更新成功",
  "data": {
    "id": 1,
    "activityId": 1,
    "title": "更新后的通知标题",
    "content": "更新后的内容...",
    "publisherId": 1001,
    "publisherName": "张老师",
    "status": "PUBLISHED",
    "publishTime": "2026-03-01 10:00:00",
    "createTime": "2026-03-01 10:00:00",
    "updateTime": "2026-03-05 15:30:00"
  }
}
```

**错误码**

| 错误码 | 说明                     |
|--------|--------------------------|
| 401    | 未登录或 Token 无效      |
| 403    | 无权限，仅管理员/教师可操作 |
| 404    | 通知不存在               |

| pageSize | Integer | 否   | 每页数量，默认10 | 10     |

**权限**: 公开，无需登录

## 附录：数据库表结构

**activity_notice 表**

| 字段          | 类型     | 说明                         |
|---------------|----------|------------------------------|
| id            | BIGINT   | 主键，自增                   |
| activity_id   | BIGINT   | 关联活动ID                   |
| title         | VARCHAR  | 通知标题（≤200字符）         |
| content       | TEXT     | 通知内容                     |
| publisher_id  | BIGINT   | 发布人ID                     |
| publisher_name | VARCHAR | 发布人名称                   |
| status        | VARCHAR  | 状态：DRAFT/PUBLISHED，默认PUBLISHED |
| publish_time  | DATETIME | 发布时间                     |
| create_time   | DATETIME | 创建时间                     |
| update_time   | DATETIME | 更新时间                     |

> **说明**: JPA 的 `ddl-auto: update` 模式会在启动时自动创建或更新表结构，无需手动执行 SQL。
