# 校园地图导航模块 - 后端接口文档

---

## 一、接口概览

### 1.1 基础信息

| 项目 | 说明 |
|------|------|
| 基础路径 | `/api/v1/map` |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 认证方式 | Bearer Token |

### 1.2 通用响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 1.3 设施类型枚举

| 类型值 | 类型名称 | 图标颜色 |
|--------|----------|----------|
| 1 | 餐厅 | 橙色 |
| 2 | 运动场 | 绿色 |
| 3 | 教学楼 | 蓝色 |
| 4 | 宿舍 | 紫色 |

### 1.4 通用错误码

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.5 权限说明

| 操作类型 | 管理员端（Web） | 学生端（App + Web） |
|----------|----------------|---------------------|
| 标记增删改 | ✅ | ❌ |
| 地图配置 | ✅ | ❌ |
| 查看标记列表 | ✅ | ✅ |
| 设施搜索 | ✅ | ✅ |
| 路线导航 | ✅ | ✅ |
| 周边查询 | ✅ | ✅ |
| 收藏管理 | ✅ | ✅ |

## 二、数据库表设计

### 2.1 地图标记表（map_marker）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| facility_id | BIGINT | 关联设施ID（关联 campus_facility.id） |
| icon_url | VARCHAR(255) | 自定义图标URL |
| sort | INT | 排序 |
| status | TINYINT | 状态：0-禁用 1-启用 |
| deleted | TINYINT | 逻辑删除：0-未删除 1-已删除 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

> **说明**：经纬度信息存储在关联的 `campus_facility` 表中，地图模块通过 `facility_id` 关联获取。

---

### 2.2 地图配置表（map_config）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| config_key | VARCHAR(100) | 配置键 |
| config_value | TEXT | 配置值 |
| description | VARCHAR(255) | 配置说明 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

**配置项示例**：

| 配置键 | 说明 |
|--------|------|
| map_center_longitude | 地图中心经度 |
| map_center_latitude | 地图中心纬度 |
| map_zoom_level | 默认缩放级别 |
| map_boundary | 地图边界范围 |

---

### 2.3 导航记录表（navigation_log）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| from_longitude | DECIMAL(10,7) | 起点经度 |
| from_latitude | DECIMAL(10,7) | 起点纬度 |
| to_marker_id | BIGINT | 目标标记ID（关联 map_marker.id） |
| distance | DECIMAL(10,2) | 导航距离（米） |
| duration | INT | 预计时长（秒） |
| status | TINYINT | 状态：1-进行中 2-已完成 3-已取消 |
| arrive_time | DATETIME | 实际到达时间 |
| create_time | DATETIME | 创建时间 |

> **说明**：导航记录只存储 `to_marker_id`，查询时通过关联查询获取最新的目标名称和位置。

---

### 2.4 收藏表（favorite_destination）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| marker_id | BIGINT | 标记ID（关联 map_marker.id） |
| marker_name | VARCHAR(100) | 标记名称（快照） |
| longitude | DECIMAL(10,7) | 经度（快照） |
| latitude | DECIMAL(10,7) | 纬度（快照） |
| facility_type | TINYINT | 设施类型（快照） |
| remark | VARCHAR(100) | 用户备注 |
| create_time | DATETIME | 创建时间 |

> **说明**：收藏表存储关键信息的快照，当标记被删除时，收藏记录仍可显示历史位置信息。

---

### 2.5 表关系

```
campus_facility (第三阶段) 1:1 map_marker (第四阶段)
sys_user 1:N navigation_log
sys_user 1:N favorite_destination
map_marker 1:N navigation_log
map_marker 1:N favorite_destination
```

## 三、地图配置接口

### 3.1 获取地图配置

**请求路径**: `GET /api/v1/map/config`

**权限**: 登录用户均可访问

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "centerLongitude": 116.397428,
    "centerLatitude": 39.90923,
    "zoomLevel": 16,
    "boundary": {
      "northEast": {"longitude": 116.41, "latitude": 39.92},
      "southWest": {"longitude": 116.38, "latitude": 39.89}
    }
  }
}
```

---

### 3.2 更新地图配置

**请求路径**: `PUT /api/v1/map/config`

**权限**: 仅管理员

**请求体**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| centerLongitude | Double | 否 | 地图中心经度 |
| centerLatitude | Double | 否 | 地图中心纬度 |
| zoomLevel | Integer | 否 | 缩放级别（1-20） |
| boundary | String | 否 | 边界范围（JSON格式） |

**响应示例**:

```json
{
  "code": 200,
  "message": "地图配置更新成功",
  "data": null
}
```

---

### 3.3 获取配置项

**请求路径**: `GET /api/v1/map/config/item/{configKey}`

**路径参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| configKey | String | 是 | 配置键 |

## 七、路线导航接口

### 7.1 发起导航

**请求路径**: `POST /api/v1/map/navigation`

**权限**: 登录用户均可访问

**请求体**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fromLongitude | Double | 是 | 起点经度 |
| fromLatitude | Double | 是 | 起点纬度 |
| toMarkerId | Long | 是 | 目标标记ID |

> **说明**：创建导航记录并返回路线信息。目标名称和位置从关联表实时查询。

**响应示例**:

```json
{

    "navigationId": 1,
    "fromLongitude": 116.397000,
    "fromLatitude": 39.908000,
    "toMarkerId": 1,
    "toMarkerName": "第一学生餐厅",
    "toLongitude": 116.397428,
    "toLatitude": 39.90923,
    "distance": 150.5,
    "estimatedTime": 120,
    "routePoints": [
      {"longitude": 116.397000, "latitude": 39.908000},
      {"longitude": 116.397200, "latitude": 39.908500},
      {"longitude": 116.397428, "latitude": 39.90923}
    ]
  }
}
```

### 7.2 获取导航路线

**请求路径**: `GET /api/v1/map/navigation/route`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fromLongitude | Double | 是 | 起点经度 |
| fromLatitude | Double | 是 | 起点纬度 |
| toLongitude | Double | 是 | 终点经度 |
| toLatitude | Double | 是 | 终点纬度 |
| mode | String | 否 | 出行方式：walking（步行，默认）、driving（驾车） |

> **使用场景**：用户预览路线时调用，不创建导航记录。

        "duration": 40,

        "endPoint": {"longitude": 116.397100, "latitude": 39.908050}
      },
      {
        "instruction": "左转进入主路",
        "distance": 200,

## 十四、数据一致性保障

### 14.1 设计原则

| 原则 | 说明 |
|------|------|
| **单一数据源** | 经纬度只存储在 `campus_facility` 表中 |
| **标记表简化** | `map_marker` 只负责展示配置，不重复存储位置信息 |
| **逻辑删除** | 设施和标记删除时执行逻辑删除，保持数据可追溯 |
| **快照存储** | 收藏表存储关键信息快照，防止关联失效 |

### 14.2 位置信息同步流程

```
场景1：新建设施
    ↓
管理员在第三阶段录入设施信息（包括经纬度）
    ↓
系统自动创建 map_marker 记录
    ↓
学生端地图自动显示该设施

场景2：设施位置变更
    ↓
管理员在第三阶段修改设施经纬度
    ↓
map_marker 通过关联查询自动获取新位置
    ↓
学生端地图实时显示新位置

场景3：设施删除
    ↓
管理员在第三阶段删除设施
    ↓
执行逻辑删除（deleted=1）
    ↓
导航历史仍可显示历史记录
    ↓
收藏记录仍可显示快照信息
```

### 14.3 数据库操作示例

```sql
-- 新增设施时，同时创建标记（Service层实现）
@Transactional
public void createFacility(FacilityDTO dto) {
    CampusFacility facility = new CampusFacility();
    facility.setLongitude(dto.getLongitude());
    facility.setLatitude(dto.getLatitude());
    facilityMapper.insert(facility);

    MapMarker marker = new MapMarker();
    marker.setFacilityId(facility.getId());
    marker.setStatus(1);
    markerMapper.insert(marker);
}

-- 查询标记时关联设施表获取位置
SELECT m.*, f.longitude, f.latitude, f.facility_name
FROM map_marker m
LEFT JOIN campus_facility f ON m.facility_id = f.id
WHERE m.status = 1 AND m.deleted = 0;

-- 查询导航历史时关联获取最新位置
SELECT n.*, f.longitude AS to_longitude, f.latitude AS to_latitude,
       f.facility_name AS to_marker_name
FROM navigation_log n
LEFT JOIN map_marker m ON n.to_marker_id = m.id
LEFT JOIN campus_facility f ON m.facility_id = f.id
WHERE n.user_id = ?;

-- 收藏时存储快照
INSERT INTO favorite_destination (user_id, marker_id, marker_name,
    longitude, latitude, facility_type, remark)
SELECT ?, m.id, f.facility_name, f.longitude, f.latitude,
       f.facility_type, ?
FROM map_marker m
LEFT JOIN campus_facility f ON m.facility_id = f.id
WHERE m.id = ?;

-- 逻辑删除设施和标记
UPDATE campus_facility SET deleted = 1 WHERE id = ?;
UPDATE map_marker SET deleted = 1 WHERE facility_id = ?;
```

### 14.4 周边距离计算（数据库 Haversine 公式）

```sql
-- 查询周边500米范围内的设施
SELECT
    m.id,
    m.facility_id,
    f.facility_name,
    f.longitude,
    f.latitude,
    (
        6371 * acos(
            cos(radians(39.908000)) * cos(radians(f.latitude)) *
            cos(radians(f.longitude) - radians(116.397000)) +
            sin(radians(39.908000)) * sin(radians(f.latitude))
        )
    ) AS distance_km
FROM map_marker m
LEFT JOIN campus_facility f ON m.facility_id = f.id
WHERE m.status = 1 AND m.deleted = 0
HAVING distance_km <= 0.5
ORDER BY distance_km;
```

> **说明**：使用数据库 Haversine 公式计算距离，无需调用第三方API，减少API配额消耗。
