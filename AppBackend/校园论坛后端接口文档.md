# 校园论坛模块后端接口文档

## 一、接口说明

### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| 基础URL | `/api/forum` |
| 认证方式 | JWT Token (Header: Authorization: Bearer {token}) |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |

### 1.2 通用响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码 (200=成功, 400=参数错误, 401=未登录, 403=无权限, 500=服务器错误) |
| message | String | 提示信息 |
| data | Object | 响应数据 |

### 1.3 分页响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "content": [],
    "pageNum": 1,
    "pageSize": 10,
    "total": 100,
    "pages": 10
  }
}
```

## 二、帖子管理

### 2.1 发布帖子

**接口地址**: `POST /api/forum/posts`

**请求头**:
```
Authorization: Bearer {token}
```

**请求参数**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | String | 是 | 帖子标题 (最大200字符) |
| content | String | 是 | 帖子内容 |
| images | String | 否 | 图片URL列表 (JSON数组格式，如: `["url1","url2"]`) |
| topicId | Long | 否 | 话题ID |
| isAnonymous | Integer | 否 | 是否匿名发布 (0-否, 1-是)，默认0 |

**请求示例**:
```json
{
  "title": "考研经验分享",
  "content": "分享一下我的考研经验，希望能帮助到大家...",
  "images": "[\"https://example.com/img1.jpg\"]",
  "topicId": 1,
  "isAnonymous": 0
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "发布成功",
  "data": {
    "id": 1,
    "title": "考研经验分享",
    "content": "分享一下我的考研经验，希望能帮助到大家...",
    "images": "[\"https://example.com/img1.jpg\"]",
    "topicId": 1,
    "isAnonymous": 0,
    "viewCount": 0,
    "likeCount": 0,
    "commentCount": 0,
    "status": "PUBLISHED",
    "createTime": "2026-03-17T10:30:00"
  }
}
```

**接口地址**: `GET /api/forum/audit/posts`

**请求头**:
```
Authorization: Bearer {token}
```

**查询参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | 否 | 页码 |
| pageSize | Integer | 否 | 每页数量 |

**响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "content": [
      {
        "id": 1,
        "userId": 1,
        "username": "张三",
        "title": "待审核帖子",
        "content": "内容...",
        "status": "PENDING",
        "createTime": "2026-03-17T10:00:00"
      }
    ],
    "pageNum": 1,
    "pageSize": 20,
    "total": 10
  }
}
```

### 8.2 审核帖子

**接口地址**: `PUT /api/forum/audit/posts/{id}`

**请求头**:
```
Authorization: Bearer {token}
```

**路径参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| id | Long | 帖子ID |

**请求参数**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | String | 是 | 审核状态 (APPROVED-通过, REJECTED-驳回, HIDDEN-隐藏) |
| reason | String | 否 | 驳回/隐藏原因 |

**请求示例**:
```json
{
  "status": "APPROVED",
  "reason": null
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "审核成功",
  "data": null
}
```

## 十一、通用说明

### 11.1 状态字段说明

| 类型 | 状态值 | 说明 |
|------|--------|------|
| 帖子状态 | PUBLISHED | 已发布 |
| 帖子状态 | DRAFT | 草稿 |
| 帖子状态 | HIDDEN | 已隐藏 |
| 帖子状态 | DELETED | 已删除 |
| 评论状态 | NORMAL | 正常 |
| 评论状态 | HIDDEN | 已隐藏 |
| 评论状态 | DELETED | 已删除 |
| 话题状态 | ACTIVE | 启用 |
| 话题状态 | INACTIVE | 禁用 |
| 举报状态 | PENDING | 待处理 |
| 举报状态 | APPROVED | 已通过 |
| 举报状态 | REJECTED | 已驳回 |
| 目标类型 | 1 | 帖子 |
| 目标类型 | 2 | 评论 |
| 布尔值 | 0 | 否 |
| 布尔值 | 1 | 是 |

### 11.2 权限说明

- **学生端接口**: 需要学生角色Token
- **管理端接口**: 需要管理员角色Token
- 部分接口需要登录才能访问，具体见各接口说明
