# 校园旧物出售模块 & 校园特惠模块 — 接口文档

> **接口基础路径**: `http://localhost:8080/api`
> **认证方式**: JWT Bearer Token（`Authorization: Bearer <token>`），部分接口无需登录即可访问
> **通用响应格式**: 统一使用 `Result<T>` 包装，其中 `code` 为状态码，`msg` 为提示信息，`data` 为业务数据
>
> **通用状态码约定**:
>
> | code  | 说明                     |
> | ----- | ------------------------ |
> | 200   | 操作成功                 |
> | 401   | 未登录 / token 过期      |
> | 403   | 无权限                   |
> | 404   | 资源不存在               |
> | 400   | 参数错误 / 业务校验失败   |
> | 500   | 服务器内部错误           |
>
> **分页响应格式**（列表接口统一）:
>
> ```json
> {
>   "code": 200,
>   "msg": "success",
>   "data": {
>
>     "total": 100,
>     "size": 10,
>     "current": 1,
>     "pages": 10
>   }
> }
> ```
>
> **通用请求参数说明**（分页列表）:
>
> | 参数     | 位置 | 类型    | 必填 | 说明                       |
> | -------- | ---- | ------- | ---- | -------------------------- |
> | current  | query | int    | 否   | 当前页码，默认 1           |
> | size     | query | int    | 否   | 每页条数，默认 10          |
> | keyword  | query | string | 否   | 搜索关键词（标题/描述）    |

# 第一部分：第五阶段 — 校园旧物出售模块

## 一、物品分类管理 (`/secondhand/category`)

### 1.1 分类列表（公开）

```
GET /api/secondhand/category/list
```

**请求参数**: 无

**响应示例**:

```json
{
  "code": 200,
  "msg": "success",
  "data": [
    { "id": 1, "categoryName": "数码产品", "sort": 1 },
    { "id": 2, "categoryName": "书籍教材", "sort": 2 },
    { "id": 3, "categoryName": "生活用品", "sort": 3 }
  ]
}
```

| 字段          | 类型    | 说明             |
| ------------- | ------- | ---------------- |
| id            | Long    | 分类ID           |
| categoryName  | String  | 分类名称         |
| sort          | Integer | 排序值（越小越前）|

---

### 1.2 新增分类（管理员）

```
POST /api/secondhand/category
```

**请求头**: `Authorization: Bearer <token>`（需管理员权限）

**请求体**:

```json
{
  "categoryName": "运动户外",
  "sort": 4
}
```

| 字段         | 类型    | 必填 | 说明           |
| ------------ | ------- | ---- | -------------- |
| categoryName | String  | 是   | 分类名称（2-20字）|
| sort         | Integer | 否   | 排序值，默认 0  |

**响应示例**:

```json
{
  "code": 200,
  "msg": "创建成功",
  "data": { "id": 4, "categoryName": "运动户外", "sort": 4 }
}
```

---

### 1.3 编辑分类（管理员）

```
PUT /api/secondhand/category/{id}
```

**路径参数**: `id` — 分类 ID

**请求体**（全部字段均为可选，只传需要修改的字段）:

```json
{
  "categoryName": "运动装备",
  "sort": 5
}
```

**响应**: `{"code": 200, "msg": "更新成功"}`

---

### 1.4 删除分类（管理员）

```
DELETE /api/secondhand/category/{id}
```

**说明**: 删除前检查该分类下是否有物品，若有则拒绝删除。

**响应**:

```json
{
  "code": 200,
  "msg": "删除成功"
}
```

## 二、物品管理 (`/secondhand/item`)

### 2.1 发布物品

```
POST /api/secondhand/item
```

**请求头**: `Authorization: Bearer <token>`（需登录）

**请求体**:

```json
{
  "categoryId": 1,
  "title": "iPad Air 4 256G 平板",
  "description": "2023年购买，功能正常，屏幕无划痕，配件齐全。",
  "images": [
    "https://cdn.example.com/img/item1.jpg",
    "https://cdn.example.com/img/item2.jpg"
  ],
  "price": 2800.00,
  "originalPrice": 4999.00,
  "condition": 3,
  "location": "图书馆门口"
}
```

| 字段           | 类型      | 必填 | 说明                              |
| -------------- | --------- | ---- | -------------------------------- |
| categoryId     | Long      | 是   | 分类 ID                          |
| title          | String    | 是   | 物品标题（4-50字）               |
| description    | String    | 是   | 物品描述（10-500字）             |
| images         | String[]  | 是   | 图片 URL 数组，最多 9 张         |
| price          | BigDecimal| 是   | 售价（0.01 ~ 999999）            |
| originalPrice  | BigDecimal| 否   | 原价                             |
| condition      | Integer   | 是   | 新旧程度：1-全新 2-几乎全新 3-轻微使用痕迹 4-明显使用痕迹 5-仅限零件 |
| location       | String    | 否   | 期望交易地点                      |

**响应**:

```json
{
  "code": 200,
  "msg": "发布成功",
  "data": { "id": 10 }
}
```

> 物品发布后状态默认为 `2-在售`，无需审核即可直接展示。

---

### 2.2 编辑物品

```
PUT /api/secondhand/item/{id}
```

**路径参数**: `id` — 物品 ID

**请求头**: `Authorization: Bearer <token>`（需为物品所有者）

**请求体**: 同 2.1，可传部分字段只更新对应项。

**业务规则**:
- 在售中 (`status=2`) 的物品可直接编辑
- 已售出 (`status=3`) 的物品不可编辑

**响应**: `{"code": 200, "msg": "更新成功"}`

---

### 2.3 删除物品

```
DELETE /api/secondhand/item/{id}
```

**请求头**: `Authorization: Bearer <token>`（需为物品所有者或管理员）

**说明**: 物理删除物品，同时删除相关收藏记录。

**响应**: `{"code": 200, "msg": "删除成功"}`

## 三、物品收藏 (`/secondhand/favorite`)

### 3.1 收藏物品

```
POST /api/secondhand/favorite/{id}
```

**请求头**: `Authorization: Bearer <token>`（需登录）

**路径参数**: `id` — 物品 ID

**业务规则**:
- 不能收藏自己的物品
- 不能重复收藏
- 收藏后物品的 favorite_count 自动 +1

**响应**:
- 收藏成功: `{"code": 200, "msg": "收藏成功"}`
- 已收藏: `{"code": 400, "msg": "已收藏过该物品"}`
- 物品不存在: `{"code": 404, "msg": "物品不存在"}`

---

### 3.2 取消收藏

```
DELETE /api/secondhand/favorite/{id}
```

**请求头**: `Authorization: Bearer <token>`（需登录）

**路径参数**: `id` — 物品 ID

**业务规则**: 取消后物品的 favorite_count 自动 -1。

**响应**: `{"code": 200, "msg": "取消收藏成功"}`

---

## 四、聊天会话 (`/chat/session`)

### 4.1 创建/获取会话

```
POST /api/chat/session/{itemId}
```

**请求头**: `Authorization: Bearer <token>`（需登录）

**路径参数**: `itemId` — 物品 ID

**业务规则**:
- 不能与自己聊天
- 同一买家+同一物品组合，只创建一个会话（幂等）
- 创建会话后自动推送一条系统消息

**响应**:
返回 `ChatDTO.SessionVO`（完整会话对象），响应示例如下：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "sessionId": 8,
    "itemId": 10,
    "itemTitle": "iPad Air 4",
    "itemImage": "https://...",
    "itemPrice": 2800.00,
    "sellerId": 5,
    "sellerName": "张三",
    "lastMessage": "您好，请问还在吗？",
    "lastTime": "2024-03-16 14:30:00",
    "unreadCount": 1
  }
}
```

## 五、聊天消息 (`/chat/message`)

```
POST /api/chat/message
```

**请求头**: `Authorization: Bearer <token>`（需登录）

**请求体**:

```json
{
  "sessionId": 8,
  "content": "您好，请问还在吗？",
  "messageType": 1
}
```

| 字段         | 类型    | 必填 | 说明                                  |
| ------------ | ------- | ---- | ------------------------------------ |
| sessionId    | Long    | 是   | 会话 ID                              |

| messageType  | Integer | 否   | 消息类型：1-文本 2-图片 3-位置，默认 1 |

**业务规则**:
- 发送后更新会话的 last_message 和 last_time
- 消息类型为图片时，content 填写图片 URL
- 消息类型为位置时，content 填写位置描述文字

**响应**:

```json
{
  "code": 200,
  "msg": "发送成功",
  "data": {
    "id": 200,
    "sessionId": 8,
    "senderId": 3,
    "content": "您好，请问还在吗？",
    "messageType": 1,
    "isRead": false,
    "createTime": "2024-03-16 14:30:00"
  }
}
```

---

GET /api/secondhand/statistics
```

**请求头**: `Authorization: Bearer <token>`（需管理员权限）

**请求参数**:

| 参数     | 位置  | 类型   | 必填 | 说明                        |
| -------- | ----- | ------ | ---- | -------------------------- |
| startDate | query | String | 否   | 统计开始日期（yyyy-MM-dd） |
| endDate   | query | String | 否   | 统计结束日期（yyyy-MM-dd） |

**响应示例**:

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "totalItems": 856,
    "onSaleItems": 620,
    "soldItems": 198,
    "offlineItems": 38,
    "dailyPublishTrend": [
      { "date": "2024-03-10", "count": 15 },
      { "date": "2024-03-11", "count": 22 }
    ],
    "categoryDistribution": [
      { "categoryName": "数码产品", "count": 180 },
      { "categoryName": "书籍教材", "count": 220 }
    ]
  }
}
```
