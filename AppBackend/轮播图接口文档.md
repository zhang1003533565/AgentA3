# 轮播图管理接口文档

> **基础路径**: `http://localhost:8080`  
> **认证方式**: JWT Bearer Token（在 Header 中添加 `Authorization: Bearer <token>`）  
> **说明**: 仅 `getEnabledBanners` 接口无需认证，其余接口需管理员（ADMIN）或教师（TEACHER）权限。

---

## 1. 上传轮播图

上传图片并创建轮播图记录。

**请求**

```
POST /api/carousel-banners/upload
Content-Type: multipart/form-data
Authorization: Bearer <token>
```

**参数**

| 参数名    | 类型 | 位置   | 必填 | 说明                    | 示例值                        |
|-----------|------|--------|------|-------------------------|-------------------------------|
| file      | File | body   | 是   | 轮播图图片文件（≤5MB）  |                               |
| title     | Str  | query  | 否   | 标题                    | 校园迎新活动                  |
| linkUrl   | Str  | query  | 否   | 跳转链接（可选）        | https://example.com/activity |
| sortOrder | Int  | query  | 否   | 排序值，值越小越靠前，默认0 | 0                          |

**请求示例（curl）**

```bash
curl -X POST "http://localhost:8080/api/carousel-banners/upload?title=校园迎新活动&linkUrl=https://example.com/activity/1&sortOrder=0" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -F "file=@/path/to/banner.jpg"
```

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "轮播图上传成功",
  "data": {
    "id": 1,
    "imageUrl": "http://localhost:8080/uploads/20240414210224_banner.jpg",
    "title": "校园迎新活动",
    "linkUrl": "https://example.com/activity/1",
    "sortOrder": 0,
    "enabled": true,
    "createTime": "2024-04-14 21:02:24",
    "updateTime": "2024-04-14 21:02:24"
  }
}
```

**错误码**

| 错误码 | 说明                             |
|--------|----------------------------------|
| 401    | 未登录或 Token 无效              |
| 403    | 无权限，仅管理员/教师可操作       |
| 400    | 文件为空或格式不支持             |

获取所有已启用的轮播图，供前端展示用，无需权限。

## 5. 更新轮播图

更新指定 ID 的轮播图信息，需管理员或教师权限。

**请求**

```
PUT /api/carousel-banners/{id}
Authorization: Bearer <token>
```

**路径参数**

| 参数名 | 类型 | 必填 | 说明     | 示例 |
|--------|------|------|----------|------|
| id     | Long | 是   | 轮播图ID | 1    |

**查询参数**

| 参数名    | 类型    | 必填 | 说明                  | 示例值                         |
|-----------|---------|------|-----------------------|--------------------------------|
| title     | String  | 否   | 标题                  | 新标题                         |
| linkUrl   | String  | 否   | 跳转链接（可选）      | https://example.com/activity/2 |
| sortOrder | Integer | 否   | 排序值                | 1                              |
| enabled   | Boolean | 否   | 是否启用（true/false） | true                          |

**请求示例（curl）**

```bash
curl -X PUT "http://localhost:8080/api/carousel-banners/1?title=更新标题&linkUrl=https://example.com/activity/2&sortOrder=2&enabled=true" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "轮播图更新成功",
  "data": {
    "id": 1,
    "imageUrl": "http://localhost:8080/uploads/20240414210224_banner.jpg",
    "title": "更新标题",
    "linkUrl": "https://example.com/activity/2",
    "sortOrder": 2,
    "enabled": true,
    "createTime": "2024-04-14 21:02:24",
    "updateTime": "2024-04-14 22:00:00"
  }
}
```

## 6. 删除轮播图

删除指定 ID 的轮播图，需管理员或教师权限。

**请求**

```
DELETE /api/carousel-banners/{id}
Authorization: Bearer <token>
```

**路径参数**

| 参数名 | 类型 | 必填 | 说明     | 示例 |
|--------|------|------|----------|------|
| id     | Long | 是   | 轮播图ID | 1    |

**成功响应（200）**

```json
{
  "code": 200,
  "msg": "轮播图删除成功",
  "data": null
}
```

---

## 通用响应格式

| 字段 | 类型   | 说明           |
|------|--------|----------------|
| code | Int    | 状态码，200表示成功 |
| msg  | String | 消息           |
| data | Object | 返回数据       |

## 公共错误码

| 错误码 | 说明           |
|--------|----------------|
| 200    | 成功           |
| 400    | 请求参数错误   |
| 401    | 未登录/Token无效 |
| 403    | 无权限         |
| 404    | 资源不存在     |
| 500    | 服务器内部错误 |

## 附录：使用 Apifox / Postman 测试

上传轮播图接口推荐使用 Apifox 或 Postman 测试：

1. **请求方法**: `POST`
2. **URL**: `http://localhost:8080/api/carousel-banners/upload`
3. **Headers**: 添加 `Authorization: Bearer <你的JWT>`
4. **Body**: 选择 `form-data`
   - `file` → 类型选 **File**，选择本地图片文件
   - `title`（可选）→ 类型选 **Text**
   - `linkUrl`（可选）→ 类型选 **Text**
   - `sortOrder`（可选）→ 类型选 **Text**
