# 智慧校园 - 接口文档

## 基础信息

- **基础URL**: `http://localhost:8080/api`
- **认证方式**: JWT Bearer Token
- **请求格式**: JSON
- **响应格式**: JSON

## 统一响应格式

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

### 状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 操作成功 |
| 400 | 请求参数错误 |
| 401 | 未授权/登录过期 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 一、认证接口

### 1.1 用户登录

**请求**

```
POST /auth/login
```

```json
{
  "username": "string",
  "password": "string"
}
```

**响应**

```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": 1,
    "username": "admin",
    "role": "ADMIN",
    "realName": "管理员"
  }
}
```

### 1.2 用户注册

**请求**

```
POST /auth/register
```

```json
{
  "username": "string",
  "password": "string",
  "realName": "string",
  "phone": "string",
  "email": "string",
  "studentNo": "string",
  "role": "STUDENT"
}
```

**说明**: `role` 可选值: `STUDENT`(学生), `TEACHER`(教师), `ADMIN`(管理员，默认STUDENT)

**响应**

```json
{
  "code": 200,
  "msg": "注册成功",
  "data": null
}
```

### 1.3 获取当前用户信息

**请求**

```
GET /auth/current
```

**请求头**: `Authorization: Bearer <token>`

**响应**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 1,
    "username": "admin",
    "realName": "管理员",
    "phone": "13800138000",
    "email": "admin@campus.com",
    "role": "ADMIN",
    "avatar": "https://...",
    "createTime": "2026-01-01 10:00:00"
  }
}
```

### 1.4 修改密码

**请求**

```
PUT /auth/password
```

```json
{
  "oldPassword": "string",
  "newPassword": "string"
}
```

**响应**

```json
{
  "code": 200,
  "msg": "密码修改成功",
  "data": null
}
```

## 二、用户管理接口

### 2.1 用户列表（管理员）

**请求**

```
GET /users
```

**请求参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| page | int | 页码，默认1 |
| size | int | 每页数量，默认10 |
| username | string | 用户名（模糊搜索） |
| role | string | 角色筛选 |
| status | int | 状态筛选(0-禁用,1-启用) |

**响应**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "records": [
      {
        "id": 1,
        "username": "zhangsan",
        "realName": "张三",
        "studentNo": "2021001",
        "phone": "13800138000",
        "email": "zhangsan@campus.com",
        "role": "STUDENT",
        "college": "计算机学院",
        "major": "软件工程",
        "className": "软件21-1班",
        "status": 1,
        "createTime": "2026-01-01 10:00:00"
      }
    ],
    "total": 100,
    "page": 1,
    "size": 10
  }
}
```

### 2.2 更新用户（管理员）
