# 智慧校园

## 项目概述

本项目是一个基于前后端分离架构的智慧校园综合服务平台，包含移动端 App 和 Web 管理后台，共用一套后端接口与数据库。

## 技术栈


| 端           | 技术         |
| ------------ | ------------ |
| 移动端 App   | uni-app      |
| Web 管理后台 | React + Vite |
| 后端服务     | Spring Boot  |
| 数据库       | MySQL        |
| 缓存         | Redis        |

## 项目结构

```
SmartCampus/
├── AppBackend/          # Spring Boot 后端服务
│   └── src/main/java/com/example/appbackend/
│       ├── config/      # 配置类
│       ├── controller/  # 控制层
│       ├── service/     # 业务层
│       ├── entity/      # 实体类
│       ├── dto/         # 数据传输对象
│       ├── repository/  # 数据访问层
│       └── util/        # 工具类
├── AppFrontend/         # uni-app 移动端
│   └── pages/           # 页面目录
└── AppWeb/              # React Web 管理后台
    └── src/
        ├── pages/       # 页面组件
        ├── api/         # 接口请求
        └── utils/       # 工具函数
```

### 模块概述

**第一阶段 - 校园活动报名模块**
- 活动浏览、报名、签到
- 报名审核、数据统计
- 消息通知、收藏评论

**第二阶段 - 校园论坛模块**
- 帖子发布、评论互动
- 话题讨论、用户关注
- 内容审核、举报处理

**第三阶段 - 校园设施模块**
- 餐厅管理（档口、菜系）
- 教学楼管理（教室、座位）
- 宿舍管理（房间、床位选择）
- 运动场管理

**第四阶段 - 校园地图导航模块**
- 校园地图展示
- 设施位置标记
- 路线导航

**第五阶段 - 校园旧物出售模块**
- 二手物品发布
- 在线沟通交流
- 线下见面交易

**第六阶段 - 校园特惠模块**
- 商家入驻认证
- 优惠活动发布
- 优惠券领取核销

**第七阶段 - AI创作模块**
- 故事转剧本/分镜
- AI生成人物/场景图片
- AI生成视频并拼接

**第八阶段 - 系统优化与完善**
- 性能优化、安全加固
- 用户体验改进、代码质量提升
- 运维监控、持续改进

## 接口规范

### 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 状态码定义


| 状态码 | 说明                   |
| ------ | ---------------------- |
| 200    | 操作成功               |
| 400    | 请求参数错误           |
| 401    | 未授权/登录过期        |
| 403    | 权限不足               |
| 404    | 资源不存在             |
| 500    | 服务器内部错误         |
| 1001   | 业务逻辑错误（自定义） |

## 部署说明

### 环境要求

- JDK 17+
- MySQL 8.0+
- Redis 6.0+
- Node.js 18+

### 启动步骤

1. **启动 MySQL 和 Redis**
2. **启动后端服务**
   ```bash
   cd AppBackend
   mvn spring-boot:run
   ```
3. **启动 Web 管理后台**
   ```bash
   cd AppWeb
   npm install
   npm run dev
   ```
4. **使用 HBuilderX 运行 uni-app**
